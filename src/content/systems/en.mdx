## Entropy Analysis of Binary Payloads

When analyzing unknown firmware images, one of the primary hurdles is locating where obfuscation, compression, or encryption begins. We utilize **Shannon Entropy** to map information density across raw binary buffers.

A uniform distribution of byte values yields an entropy of exactly $8.0$ bits per byte, indicating maximum chaos (typically compressed files or AES-encrypted blobs).

$$
H(S) = -\sum_{i=0}^{255} P(b_i) \log_2 P(b_i)
$$

Where $P(b_i)$ is the empirical probability of occurrence of the byte value $b_i$ within a sliding window $S$.

### Automated Entropy Scanner (Python)

Below is a utility routinely executed within my local toolchain to inspect firmware sections prior to disassembling them with Ghidra:

```python
def calculate_entropy(data: bytes) -> float:
    if not data:
        return 0.0
    
    # Calculate occurrence frequency of each byte value
    counts = [0] * 256
    for byte in data:
        counts[byte] += 1
        
    entropy = 0.0
    total_len = len(data)
    
    for count in counts:
        if count == 0:
            continue
        p = count / total_len
        entropy -= p * math.log2(p)
        
    return entropy
```
