## Análise de Entropia de Payloads Binários

Ao analisar imagens de firmware desconhecidas, uma das principais dificuldades é localizar onde começa a ofuscação, compressão ou criptografia. Utilizamos a **Entropia de Shannon** para mapear a densidade de informação em buffers binários brutos.

Uma distribuição uniforme de valores de bytes resulta em uma entropia de exatamente $8.0$ bits por byte, indicando caos máximo (geralmente arquivos compactados ou blocos criptografados com AES).

$$
H(S) = -\sum_{i=0}^{255} P(b_i) \log_2 P(b_i)
$$

Onde $P(b_i)$ representa a probabilidade empírica de ocorrência do valor do byte $b_i$ dentro de uma janela deslizante $S$.

### Scanner de Entropia Automatizado (Python)

Abaixo está um utilitário que executo rotineiramente em minha ferramenta local para inspecionar seções de firmware antes de analisá-las com o Ghidra:

```python
def calculate_entropy(data: bytes) -> float:
    if not data:
        return 0.0
    
    # Calcula a frequência de ocorrência de cada valor de byte
    counts = [0] * 256
    for byte in data:
        counts[byte] += 1
        
    entropy = 0.0
    total_len = len(data)
    
    for count in counts:
        if count == 0:
            continue
        p = count / total_len
        entropy -= p * math.log2(p)
        
    return entropy
```
